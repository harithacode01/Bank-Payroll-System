# Bank Payroll System

A web-based Employee Payroll Management System developed using ASP.NET Web Forms, C# and SQL Server.

## Features

- Employee Management
- Payroll Entry
- Salary Calculation
- PF and ESI Management
- View Payroll Records
- Database Storage

## Technologies Used

- ASP.NET Web Forms
- C#
- HTML
- CSS
- Bootstrap
- SQL Server
- Visual Studio

## Salary Calculation

Gross Salary = Basic Salary + HRA + DA + Other Allowance

Net Salary = Gross Salary - PF - ESI

## Database

SQL Server LocalDB is used to store employee and payroll information.
